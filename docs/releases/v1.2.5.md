# v1.2.5

## 版本简介

本版本完善 1Panel 反向代理部署支持，并修复 D1、KV、R2 资源创建与管理按钮的交互反馈。

## 主要变化

- 新增独立的 1Panel Docker Compose 编排和反向代理配置说明，支持控制台域名及其项目子域名。
- 修复资源创建按钮样式异常，增加标准表单提交、创建中状态和重复提交保护。
- 创建失败时在资源名称输入框附近显示明确错误，同时保留全局错误通知。
- 统一 D1、KV、R2 数据管理界面的主要、次要和图标按钮样式，并补充创建流程回归测试。

## 升级说明

本次只发布 GitHub 应用代码包，不发布 Docker 镜像，也不包含数据库迁移。已部署实例可在“设置 > 应用版本”中指定 `v1.2.5` 在线升级。

`docker-compose.1panel.yml` 属于服务器部署配置，不会被在线升级自动覆盖；新部署或重新编排时需要从本版本源码中手动使用该文件并配置对应环境变量。
