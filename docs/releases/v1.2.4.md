# v1.2.4

## 版本简介

本版本将生产 Docker Compose 部署收敛为可直接粘贴到 1Panel 的远程镜像编排。

## 主要变化

- 生产编排只拉取明确的 Docker Hub SemVer 镜像，不再在服务器构建源码。
- Caddy 配置内置到镜像，不再要求服务器上传或挂载 `Caddyfile`。
- 使用 `CCFWP_DATA_DIR` 指定稳定的宿主机数据目录，兼容项目运行容器的直接挂载要求。
- 预检脚本校验远程镜像版本、数据目录和生产编排的无源码依赖特性。

## 升级说明

发布并部署本版本 Docker 镜像后，后续应用代码仍可通过已签名的 GitHub Release 在线升级；
必须保留原有 `CCFWP_DATA_DIR`，不要使用 `latest` 或更换数据目录。
