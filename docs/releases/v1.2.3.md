# v1.2.3

## 版本简介

本版本新增仓库级发布 Skill，将版本准备、验证、镜像发布、Tag 发布和签名产物检查固化为可复用流程。

## 主要变化

- 新增 `$publish-project-release`，支持准备、发布、监控和诊断项目版本。
- 强制使用严格 SemVer、版本说明文件和不可变 Tag/Release。
- 明确区分本机 Docker 镜像发布与 GitHub 签名应用包发布。
- 固化 CI、Cosign、双架构 `tar.gz` 资产和发布后验证要求。

## 升级说明

本版本不改变 Docker 运行环境、升级器或应用数据，无需更新 Docker 镜像或配置。
