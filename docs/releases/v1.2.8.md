# v1.2.8

## 版本简介

本版本修复 1Panel 容器升级后的健康检查误判，以及原有 Worker/Pages 项目因残留 Docker 网络而无法启动的问题。

## 主要变化

- Docker 健康检查改用 Node 原生 HTTP 客户端发送控制台 `Host`，避免请求被主机白名单以 `421` 拒绝。
- 健康探针失败时记录 HTTP 状态与响应摘要，便于直接从 Docker 健康日志定位配置问题。
- Manager 容器重建后，清理旧项目网络前先确认当前 Manager 是否仍连接该网络。
- 将 Docker 明确返回的“容器未连接该网络”视为幂等清理成功，同时继续上报其他 Docker 500 错误。
- 增加旧网络清理、并发断开和异常保留的回归测试，并更新 1Panel 故障排查说明。

## 升级说明

无需数据库迁移，也无需发布新的 Docker 镜像；可直接通过控制台在线升级应用版本。尚未更新 1Panel
编排的部署，需要先使用仓库最新版 `docker-compose.1panel.yml` 重新创建容器，使修正后的健康检查配置生效。
