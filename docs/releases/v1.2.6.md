# v1.2.6

## 版本简介

本版本更新 CCFWP 控制台品牌标识，并修复资源创建按钮无法正常操作的问题。

## 主要变化

- 使用统一的 CCFWP 图形标识替换控制台 Logo、登录页 Logo 和浏览器标签页图标。
- 增加 32px、192px 和 Apple Touch Icon 图标资源，更新页面标题和主题色。
- 修复 D1、KV、R2 资源创建按钮在名称为空时不可点击的问题。
- 名称为空时显示中文校验提示并自动聚焦输入框，提交过程中继续防止重复创建。
- 补充资源创建按钮的回归测试。

## 升级说明

本次只发布 GitHub 应用代码包，不发布 Docker 镜像，也不包含数据库迁移。已部署实例可在“设置 > 应用版本”中指定 `v1.2.6` 在线升级。

无需修改现有 Docker、Compose 或 1Panel 配置。
