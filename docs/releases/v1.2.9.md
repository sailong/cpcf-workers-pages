# v1.2.9

## 版本简介

本版本修复 1Panel 反向代理环境中启动或停止 Worker/Pages 项目时控制接口偶发返回 502 的问题。

## 主要变化

- Manager 接入项目独立网络时将数据平面网络的 Docker 网关优先级固定为 `-1`。
- 保证 Compose/1Panel 入口网络始终作为 Manager 默认路由，避免项目网络变更中断当前控制接口连接。
- 扩展 Docker Engine 客户端，使网络连接请求支持明确传递 `GwPriority`。
- 增加 Docker API 请求体测试，并在真实运行时隔离测试中验证多个项目网络的网关优先级。
- 保持每个项目独立网络以及 Worker、Pages、D1、KV、R2 隔离边界不变。

## 升级说明

无需数据库迁移，也无需更新 Docker 镜像或 Compose 配置，可直接通过控制台在线升级。Manager 重启恢复
运行中项目时会自动使用新的网络优先级；升级完成后再执行项目启动和停止操作即可。
