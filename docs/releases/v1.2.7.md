# v1.2.7

## 版本简介

本版本修复在线应用升级在 Manager 重启较慢时误判失败的问题，并将 CI 调整为手动运行。

## 主要变化

- 将升级器的 Manager 健康检查等待窗口提升为 3 分钟，并支持通过 `CCFWP_MANAGER_HEALTH_TIMEOUT_MS` 调整。
- 健康检查超时时输出容器状态、重启状态和最近一次 Docker 健康检查结果，便于定位启动失败原因。
- Manager 关闭时主动释放长连接，并限制运行时清理等待时间，避免升级重启长期停留在执行中。
- CI 改为仅在 GitHub Actions 页面手动运行；严格 SemVer Tag 发布流程不再自动调用 CI。
- 同步更新标准 Docker Compose、1Panel 编排和部署说明。

## 升级说明

本版本修改了固定镜像中的升级器，必须先部署 `docker.io/simonchang/ccfwp-platform:v1.2.7`，再使用
GitHub Release 应用包进行在线升级。无需数据库迁移；持久化数据目录保持不变。
